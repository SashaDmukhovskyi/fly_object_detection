# Запуск системи з нуля

## 1. Встановлення інструментів

Для запуску проєкту потрібно встановити:

* Git
* Python 3
* pip
* venv
* QGroundControl
* ArduPilot SITL

Для Linux спочатку встановлюються базові пакети:

```bash
sudo apt update
sudo apt install -y git python3 python3-pip python3-venv
sudo apt install -y libgl1 libglib2.0-0
```

Ці пакети потрібні для клонування проєкту, створення Python-середовища, встановлення бібліотек і роботи OpenCV.

---

## 2. Клонування репозиторію

Проєкт завантажується з GitHub:

```bash
git clone https://github.com/SashaDmukhovskyi/fly_object_detection.git
cd fly_object_detection
```

Після клонування у папці проєкту мають бути основні директорії:

```text
fly_object_detection/
├── dataset-create/
├── target-detection-CV/
├── fly-control/
├── videos/
├── README.md
├── requirements.txt
└── .gitignore
```

---

## 3. Створення віртуального середовища

У головній папці проєкту потрібно створити окреме Python-середовище:

```bash
python3 -m venv venv
```

Активувати середовище на Linux:

```bash
source venv/bin/activate
```

Після цього в терміналі має з’явитися позначка:

```text
(venv)
```

---

## 4. Встановлення залежностей Python

У головній папці проєкту встановлюються бібліотеки з `requirements.txt`:

```bash
pip install -r requirements.txt
```

Якщо потрібно запускати саме частину з керуванням через MAVLink, можна також перейти в папку `fly-control` і встановити її залежності:

```bash
cd fly-control
pip install -r requirements.txt
cd ..
```

Основні бібліотеки, які використовуються в проєкті:

```text
ultralytics
opencv-python
numpy
torch
pymavlink
```

`ultralytics` використовується для запуску YOLO-моделі, `opencv-python` — для зчитування та показу відео, `pymavlink` — для передавання команд у ArduPilot SITL.

---

## 5. Перевірка ваг моделі та тестового відео

У проєкті має бути готова навчена модель:

```text
fly-control/models/best.pt
```

Також має бути тестове відео:

```text
videos/test_video.avi
```

Модель `best.pt` використовується для виявлення повітряної цілі на кадрах відео. Відео `test_video.avi` використовується для швидкої перевірки роботи системи.

Якщо програма не знаходить відео, потрібно перевірити шлях у файлі:

```text
fly-control/yolo_mavlink_sitl_guidance.py
```

Для структури, де папка `videos` лежить у корені проєкту, шлях має бути таким:

```python
VIDEO_PATH = "../videos/test_video.avi"
```

## 6. Встановлення QGroundControl на Linux

QGroundControl потрібен для візуального перегляду роботи симулятора. У ньому можна бачити дрон на карті та перевіряти його стан під час запуску SITL.

Спочатку потрібно встановити пакети для роботи QGroundControl:

```bash
sudo apt install -y gstreamer1.0-plugins-bad gstreamer1.0-libav gstreamer1.0-gl
sudo apt install -y libfuse2
sudo usermod -a -G dialout $USER
```

Після цього потрібно вийти з системи й зайти знову, щоб оновилися права користувача.

Далі потрібно завантажити файл QGroundControl AppImage з офіційної сторінки:

```text
https://docs.qgroundcontrol.com/master/en/qgc-user-guide/getting_started/download_and_install.html
```

Після завантаження перейти в папку з файлом, наприклад:

```bash
cd ~/Downloads
```

Зробити файл виконуваним:

```bash
chmod +x QGroundControl-x86_64.AppImage
```

Запустити QGroundControl:

```bash
./QGroundControl-x86_64.AppImage
```

Якщо назва файлу відрізняється, потрібно використати фактичну назву завантаженого AppImage.

## 7. Встановлення ArduPilot SITL

ArduPilot SITL потрібен для симуляції польоту без реального БПЛА. Його краще встановити окремо, наприклад у домашній директорії.

Перейти в домашню папку:

```bash
cd ~
```

Клонувати ArduPilot:

```bash
git clone --recurse-submodules https://github.com/ArduPilot/ardupilot.git
cd ardupilot
```

Встановити залежності:

```bash
Tools/environment_install/install-prereqs-ubuntu.sh -y
```

Після встановлення виконати:

```bash
. ~/.profile
```

Потім бажано закрити термінал і відкрити його заново.

---

## 8. Запуск ArduPilot SITL

У першому терміналі запускається симулятор ArduCopter:

```bash
cd ~/ardupilot
python3 Tools/autotest/sim_vehicle.py -v ArduCopter --console --map --out=udp:127.0.0.1:14551
```

Ця команда запускає SITL і відкриває MAVLink-вихід на порт:

```text
udp:127.0.0.1:14551
```

Саме до цього порту підключається скрипт з папки `fly-control`.

---

## 9. Запуск QGroundControl

У другому терміналі або через файловий менеджер запускається QGroundControl:

```bash
cd ~/Downloads
./QGroundControl-x86_64.AppImage
```

Після запуску QGroundControl має підключитися до симулятора. У вікні програми має з’явитися дрон на карті.

---

## 10. Запуск основного скрипта системи

У третьому терміналі потрібно перейти в папку проєкту:

```bash
cd ~/fly_object_detection/fly-control
```

Активувати віртуальне середовище:

```bash
source ../venv/bin/activate
```

Запустити основний файл:

```bash
python3 yolo_mavlink_sitl_guidance.py
```

Після запуску програма виконує такі дії:

1. Завантажує YOLO-модель з файлу `best.pt`.
2. Відкриває тестове відео.
3. Підключається до ArduPilot SITL через MAVLink.
4. Очікує `heartbeat` від симулятора.
5. Переводить дрон у режим `GUIDED`.
6. Виконує `ARM` і `TAKEOFF` у симуляційному середовищі.
7. Зчитує кадри відео через OpenCV.
8. Передає кадри в YOLO-модель.
9. Визначає рамку повітряної цілі.
10. Обчислює центр рамки цілі.
11. Порівнює центр цілі з центром кадру.
12. Розраховує зміщення по горизонталі та вертикалі.
13. Формує команди швидкості.
14. Передає команди в ArduPilot SITL через MAVLink.
15. Відображає результат у вікні OpenCV.
16. Після завершення роботи виконує посадку.

---

## 11. Очікуваний результат

Після запуску мають працювати три частини системи:

### 1. ArduPilot SITL

У терміналі видно роботу симулятора та прийом MAVLink-команд.

### 2. QGroundControl

На карті видно дрон і його стан у симуляції.

### 3. OpenCV-вікно

Показується відео з рамкою навколо цілі, центром кадру, центром виявленої цілі та зміщенням відносно центра кадру.

Для завершення роботи потрібно натиснути:

```text
q
```

Після цього OpenCV-вікно закривається, а скрипт завершує роботу.

## 12. Перевірка детекції без SITL

Якщо потрібно перевірити тільки роботу YOLO-моделі без польотної симуляції, можна відкрити ноутбук:

```text
target-detection-CV/target_detector.ipynb
```

У ньому можна запустити модель на тестовому відео та перевірити, чи правильно вона знаходить повітряну ціль у кадрі.

У такому режимі програма не передає MAVLink-команди, а тільки обробляє відео і показує результат детекції.

## 14. Опис основних частин

### `dataset-create/`

Містить ноутбук для формування датасету з відео. У ньому відео розбивається на кадри, після чого готується розмітка для навчання YOLO.

### `target-detection-CV/`

Містить ноутбук для навчання та перевірки YOLO-моделі. У цій частині створюється конфігурація датасету, запускається навчання та перевіряється результат детекції.

### `fly-control/`

Містить основний скрипт запуску системи. Він відкриває відео, запускає модель YOLO, визначає положення цілі та передає команди в ArduPilot SITL через MAVLink.

### `videos/`

Містить тестове відео для перевірки роботи системи.

### `requirements.txt`

Містить список Python-бібліотек, потрібних для запуску проєкту.

## 15. Можливі проблеми

### Не знайдено модель

Потрібно перевірити, чи файл існує:

```text
fly-control/models/best.pt
```

### Не знайдено відео

Потрібно перевірити файл:

```text
videos/test_video.avi
```

або шлях до нього у скрипті.

### OpenCV не відкриває вікно

Потрібно перевстановити бібліотеку:

```bash
pip install opencv-python
```

### Скрипт не підключається до SITL

Потрібно перевірити, чи запущений ArduPilot SITL з параметром:

```text
--out=udp:127.0.0.1:14551
```

### QGroundControl не запускається

Потрібно перевірити, чи файл AppImage має право на виконання:

```bash
chmod +x QGroundControl-x86_64.AppImage
```

### QGroundControl не бачить симулятор

Потрібно спочатку запустити ArduPilot SITL, а потім відкрити QGroundControl.
